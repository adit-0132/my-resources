Problems of Simple RNN
A major limitation of Recurrent Neural Networks (RNNs) is the vanishing gradient problem that occurs during Backpropagation Through Time (BPTT). 

As gradients are propagated backward across multiple time steps, they are repeatedly multiplied by recurrent weights and activation-function derivatives. 

When these values are less than one, the gradient magnitude decreases exponentially, causing the gradients associated with earlier time steps to become extremely small or approach zero. 

Consequently, the corresponding weight updates become ineffective, making it difficult for the network to learn information from distant time steps.

--- slide 5 ---
This leads to another significant limitation: difficulty in learning long-term dependencies. 

A simple RNN tends to give greater importance to recent inputs while gradually losing information from earlier inputs, thereby limiting its ability to capture relationships across long sequences. 

Furthermore, RNNs suffer from sequential computation, since the hidden state at each time step depends on the hidden state from the preceding step. 

As a result, the computations cannot be fully parallelized across time steps, leading to slower training and reduced GPU utilization, particularly when processing long sequences.

Long Short Term Memory (LSTM)Hochreiter et al., 1997
Long Short-Term Memory (LSTM) is an advanced type of Recurrent Neural Network (RNN) specifically designed to overcome the vanishing gradient problem and improve the learning of long-term dependencies. 

Unlike a conventional RNN, an LSTM uses a memory cell and three main gates—
Forget gate, 
Input gate, and 
Output gate
     to regulate the flow of information through the network. 

The forget gate determines which information should be discarded, the input gate controls which new information should be stored, and the output gate determines which information should be passed to the next hidden state.

--- slide 11 ---
Most importantly, the LSTM cell state provides a relatively direct pathway for information and gradients to flow across multiple time steps, reducing the exponential decay of gradients during Backpropagation Through Time (BPTT).

This enables LSTMs to retain relevant information for longer periods and effectively learn long-term dependencies in sequential data. 

Therefore, LSTMs provide a more robust solution than simple RNNs for tasks involving long sequences, such as language modeling, speech recognition, machine translation, and time-series prediction.

LSTM Architecture
An LSTM cell consists of a cell state and three primary gates.

The forget gate determines which information from the previous cell state should be discarded.

The input gate controls the amount of new information that should be stored in the cell state. 

The output gate determines which portion of the updated cell state is exposed as the hidden state and passed to the next time step. 

The cell state acts as a long-term memory pathway, allowing relevant information to flow through multiple time steps with reduced gradient degradation.

How LSTM solves the vanishing gradient problem?
Instead of repeatedly multiplying hidden states, an LSTM updates its cell state using additive operations:


New information is added to the cell state rather than repeatedly multiplied.

Since information is added rather than repeatedly multiplied, gradients can flow backward with minimal decay. 

This mechanism is called the Constant Error Carousel (CEC). 

As a result, gradients can propagate across many time steps without vanishing. Thus solve the vanishing gradient problem.
Concept taken from CS231n: Stanford Lecture by Fei Fei Li et. al.

How LSTM Solves Long-term Dependency Issue?
Long-Term Dependency Issue : 
"The movie, which I watched last Saturday and absolutely loved, was fantastic."
Here, the verb "was" depends on “movie", not "loved". A simple RNN may forget “movie", while an LSTM can remember it through its memory cell.
How LSTM Fixes This:
LSTM introduces a memory cell (cell state) and gates that regulate the flow of information. 
The cell state acts as a memory highway, allowing information and gradients to flow almost unchanged across many time steps. 
This enables LSTMs to learn long-term dependencies and greatly reduce the vanishing gradient problem.
