Backpropagation Through Time (BPTT)
O
Unroll
Backpropagation Through Time (BPTT) is the training algorithm used for Recurrent Neural Networks (RNNs), where the network is unfolded across multiple time steps to form a deep computational graph. 

During the forward pass, the hidden state is updated sequentially using the current input and the previous hidden state, allowing the network to capture temporal dependencies. 

In the backward pass, the error is propagated from the final time step back through each preceding time step using the chain rule.

--- slide 4 ---
Backpropagation Through Time (BPTT)
O
Unroll
Since the same weights are shared across all time steps, the gradients computed at each step are accumulated before updating the parameters using gradient descent or its variants. 

BPTT enables RNNs to learn patterns in sequential data such as text, speech, and time-series signals.

Example: RNN having 4 nodes (T=4) with shared weights.

Bidirectional RNN
Forward Pass
Backward Pass
Concept taken from CS231n: Stanford Lecture by Fei Fei Li et. al.
A Bidirectional RNN (BiRNN) is a recurrent neural network that processes a sequence in both the forward and backward directions, allowing it to use both past and future context at every time step.

This helps the model better understand the meaning of each element in the sequence. 

Example: "He went to the bank to deposit money." The meaning of "bank" becomes clear from the following words ("to deposit money").
