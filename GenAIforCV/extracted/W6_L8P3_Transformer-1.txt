Image Captioning Using RNN with Spatial Context Modelling
Image captioning combines computer vision and natural language processing to generate a textual description of an image. 

In an RNN-based approach, a CNN first extracts visual features from the image, while spatial context modelling preserves information about where objects and regions are located. 

Consequently, the encoder's final hidden state, known as the context vector, is expected to capture the essential information of the entire input image.

 This context vector is then passed to the decoder to generate the output sequence.

--- slide 11 ---
The RNN/LSTM Encoder–Decoder model encodes the meaning of the whole image into a fixed-length context vector before passing it to the decoder. 

This creates an information bottleneck, as all the relevant information must be encoded into a single vector. Consequently, the model struggles to handle long or complex input sequences, especially those longer than the sequences seen during training. 

The limited capacity of the context vector can lead to the loss of important information. Furthermore, the decoder must generate the entire output sequence using only this single context vector, making it difficult to accurately recover all the information from the source sequence. 

As a result, the model's performance often degrades for long sequences and complex translation tasks.

--- slide 12 ---
Attention
Attention for context modelling is a mechanism that enables a neural network to dynamically identify and use the most relevant information from a set of inputs when producing an output. 

Instead of treating all input elements equally, attention assigns a weight to each element based on its relevance to the current context. 

In image captioning, for example, the model can focus on different spatial regions of an image depending on the word being generated. 

At each time step, the previous hidden state of the RNN acts as a query to determine which image features are most relevant. 

The weighted combination of these features forms a context vector, which is then used by the RNN to generate the next word.

--- slide 13 ---
The attention mechanism addresses these limitations by allowing the decoder to dynamically access all encoder hidden states rather than relying solely on a single context vector. 

At each decoding step, attention calculates relevance scores for the encoder hidden states, converts these scores into normalized attention weights, and computes a weighted sum to generate a step-specific context vector. 

Consequently, the decoder can focus on different location of the input image when generating different output tokens (as part of the caption). 

This reduces the information bottleneck, improves the handling of long sequences and long-term dependencies, and enables the model to align relevant input and output elements more effectively. 

Thus, attention transforms the fixed-context model into a more flexible model capable of selectively retrieving the information required for each decoding step.
