LeNet – 5[LeCun et al., 1998]
LeNet, introduced by Yann LeCun and colleagues in 1998, is one of the earliest successful convolutional neural network (CNN) architectures for handwritten digit recognition. 

The most well-known version, LeNet-5, consists of seven trainable layers: an input layer that accepts a 32 × 32 grayscale image, followed by two convolutional layers (C1 and C3) that extract local image features using learnable filters, with each convolutional layer followed by an average pooling (subsampling) layer (S2 and S4) to reduce spatial dimensions and improve robustness.
[IMAGE: image.jpeg.jpg 8.0x2.4in]
Image Source : https://medium.datadriveninvestor.com/lenet-5-a-classic-cnn-architecture-c87d0b03560d

--- slide 4 ---
After feature extraction, the network includes a fully connected layer (C5), another fully connected layer (F6), and an output layer with 10 neurons representing the digit classes (0–9). 

LeNet employs the sigmoid or hyperbolic tangent (tanh) activation functions and uses backpropagation for training. 

Its architecture demonstrated that hierarchical feature learning through convolution and pooling could achieve high accuracy while reducing the number of trainable parameters, making LeNet a foundational model that inspired modern deep convolutional neural networks.

Padding
Padding in a Convolutional Neural Network (CNN) is the process of adding extra pixels (typically zeros) around the border of an input image or feature map before applying convolution.

Prevents rapid reduction in spatial dimensions and preserves important information at the image boundaries.

AlexNet, proposed by Alex Krizhevsky, Ilya Sutskever, and Geoffrey Hinton in 2012, is a landmark deep convolutional neural network (CNN) architecture that significantly advanced large-scale image classification.
Designed for the ImageNet Large Scale Visual Recognition Challenge (ILSVRC), AlexNet consists of eight learnable layers, including five convolutional layers followed by three fully connected layers, with a final 1,000-node softmax output layer for classification.
AlexNetKrizhevsky et. al. 2012

--- slide 7 ---
The network takes 227 × 227 × 3 RGB images as input and introduces several key innovations, including the use of Rectified Linear Unit (ReLU) activation functions for faster training, overlapping max-pooling layers for spatial down-sampling, dropout in the fully connected layers to reduce overfitting, and data augmentation techniques such as image translations and horizontal flipping to improve generalization. 
AlexNet was trained using stochastic gradient descent (SGD) on GPUs, enabling efficient optimization of its approximately 60 million parameters. By achieving a substantial reduction in ImageNet classification error, AlexNet demonstrated the effectiveness of deep learning for computer vision and laid the foundation for subsequent CNN architectures such as VGGNet, GoogLeNet, and ResNet.
A. Krizhevsky, I. Sulskever, and G. E. Hinton, “ImageNet classification with deep convolutional neural networks,” Adv. Neural Inf. Process. Syst., vol. 60, no. 6, pp. 84-90, 2012.

VGGNet, proposed by Karen Simonyan and Andrew Zisserman in 2014, is a deep convolutional neural network (CNN) architecture designed to improve image classification performance by increasing network depth while using a simple and uniform design. 

The most widely used variants, VGG-16 and VGG-19, contain 16 and 19 learnable layers, respectively, composed of multiple 3 × 3 convolutional layers with a stride of 1 and padding to preserve spatial dimensions, interleaved with 2 × 2 max-pooling layers that reduce the feature map size.

--- slide 13 ---
A key design principle of VGGNet is the use of stacked 3 × 3 convolutional layers instead of larger convolutional filters. 

Specifically, three consecutive 3 × 3 convolutional layers with a stride of 1 provide the same effective receptive field as a single 7 × 7 convolutional layer, allowing the network to capture equivalent spatial context while using a more efficient architecture. 

This design offers two major advantages. 
First, increased non-linearity: each 3 × 3 convolution is followed by a ReLU activation function, so stacking three such layers introduces three non-linear transformations instead of one, enabling the network to learn more complex, hierarchical, and discriminative feature representations. 
Second, parameter efficiency: replacing a single 7 × 7 convolution with three 3 × 3 convolutions significantly reduces the number of trainable parameters.
VGG Net Simonyan and Zisserman 2014

--- slide 19 ---
GoogLeNet, introduced by Christian Szegedy and colleagues in 2014, is a deep convolutional neural network (CNN) that won the ImageNet Large Scale Visual Recognition Challenge (ILSVRC) 2014 by combining high classification accuracy with computational efficiency. It tops the ILSVRC 2014 classification challenge with a 6.7% Top-5 error rate.

The architecture consists of 22 learnable layers and is built around the novel Inception module, which processes input features through multiple parallel branches using 1 × 1, 3 × 3, and 5 × 5 convolutional filters, along with a 3 × 3 max-pooling branch. 

The outputs of these parallel operations are concatenated to capture visual information at multiple spatial scales simultaneously.
Google NetSzegedy et. al. 2014

--- slide 20 ---
To reduce computational complexity, GoogLe Net employs 1 × 1 convolutions as bottleneck layers for dimensionality reduction before the computationally expensive 3 × 3 and 5 × 5 convolutions, significantly decreasing the number of parameters. Uses only 5 million parameters—about 12× fewer than AlexNet. 

The network accepts 224 × 224 × 3 RGB images as input and replaces large fully connected layers with global average pooling, greatly reducing model size and mitigating overfitting. So, there are no FC layers in this architecture.

Additionally, auxiliary classifiers are attached to intermediate layers during training to improve gradient propagation and regularization. 

Owing to its efficient multi-scale feature extraction, reduced parameter count, and improved training strategy, GoogLe Net achieved state-of-the-art performance while using substantially fewer parameters than earlier architectures such as AlexNet and VGGNet, making it a milestone in the evolution of deep convolutional neural networks.
Google NetSzegedy et. al. 2014

It is typically implemented using a 1×1 convolution to reduce the channel depth before more computationally expensive operations.

--- slide 33 ---
GoogLeNet stacks multiple Inception modules hierarchically, allowing the network to learn increasingly abstract and scale-invariant features. 
To reduce computational cost, 1×1 convolutions are strategically used as bottleneck layers before the computationally expensive 3×3 and 5×5 convolutions, significantly decreasing the number of input channels and reducing parameters and floating-point operations. 
This design addresses the trade-off between network width and computational complexity while preserving expressive capacity.
