To overcome this limitation, separate fully connected (FC) linear transformations are applied to the input representations to produce distinct representations for different roles within the attention mechanism. 

This allows the model to learn specialized projections for computing attention scores and generating the final output, thereby increasing the expressive power and flexibility of the layer.

--- slide 15 ---
Query, Key, and Value Projections in Attention
In the attention mechanism of a Transformer, the input vectors are initially used for both computing alignment scores and generating the attention output. 

The alignment step determines how strongly different tokens relate to one another, while the attention calculation uses these relationships to produce a weighted representation. 

However, using the same representations for both purposes can limit the model’s flexibility and expressive power. 

To address this limitation, separate fully connected (FC) linear transformations are applied to the input to generate three distinct representations: Query (Q), Key (K), and Value (V).

--- slide 16 ---
Query, Key, and Value Projections in Attention
The Query and Key vectors are used to compute alignment scores in the self-attention mechanism, while the Value vectors are used to construct the final weighted output. 

Since these FC transformations can have different dimensions, the attention mechanism can operate with different key and value representations and can map the input to an output space of a different dimensionality. 

This added flexibility enables the model to learn more specialized representations and capture complex relationships and dependencies within the data.

--- slide 18 ---
Self-attention
Self-attention is a fundamental mechanism in the Transformer architecture that enables each element in a sequence to consider and weigh the importance of all other elements when generating its representation. 

The main difference between attention and self-attention lies in where the Query, Key, and Value vectors come from. 

In general attention, the Query may come from one sequence while the Key and Value vectors come from another sequence, allowing the model to focus on relevant information from a different source. 

In contrast, self-attention generates the Query, Key, and Value vectors from the same input sequence, allowing each token to attend to other tokens within that sequence. 

Thus, self-attention is a specific form of attention that enables the model to capture relationships and dependencies among elements of the same sequence.

--- slide 19 ---
In self-attention, the input vectors are passed through fully connected (FC) linear layers to produce three different representations: Query (Q), Key (K), and Value (V). 

The Query of a token is compared with the Keys of all tokens to compute attention scores, which indicate the relevance of each token to the current token. 

These scores are normalized using the Softmax function and then used to compute a weighted sum of the Value vectors, producing a context-aware representation. 

This mechanism allows the model to capture relationships and dependencies between tokens regardless of their distance in the image.

As a result, self-attention has become a core component of modern Transformer-based language models, including BERT and GPT (Generative Pre-trained Transformer).

--- slide 23 ---
Masked Self-Attention Layer
A masked self-attention layer is a variant of self-attention commonly used in autoregressive Transformer models to ensure that each token can attend only to itself and the tokens that appear before it in the sequence. 

A mask is applied to the attention scores to prevent a token from accessing future tokens during training.

Typically, the scores corresponding to future positions are set to a very large negative value before applying the Softmax function, causing their attention weights to become effectively zero. 

This prevents information from future tokens from leaking into the current prediction and ensures that the model learns to generate or predict tokens sequentially. 

Masked self-attention is therefore essential in decoder-based architectures such as GPT, where predictions must depend only on previously available information.

--- slide 25 ---
Multi-head Self-attention Layer
The Multi-Head Self-Attention layer is a key component of the Transformer architecture that allows the model to focus on different parts of an input sequence simultaneously. 

It works by transforming the input into three representations called Query (Q), Key (K), and Value (V) and calculating attention scores to determine how strongly each word should attend to other words in the sequence. 

In multi-head attention, this process is performed across multiple attention heads, allowing the model to capture different types of relationships and contextual information at the same time. The outputs from all the attention heads are then combined and passed through a linear transformation. 

This mechanism enables Transformers to understand long-range dependencies and the relationships between words efficiently, making it essential for tasks such as machine translation, text generation, and language understanding.

--- slide 26 ---
Consider the sentence:

“The cat sat on the mat because it was tired.”

 The word “it” refers to “the cat.” A Transformer needs to understand this relationship.

In self-attention, each word looks at all the other words in the sentence and determines which ones are important for understanding its meaning. 

For example, when processing “it,” the model may give a high attention score to “cat” because they are related.
Multi-head Self-attention Layer

--- slide 27 ---
Multi-head self-attention means that this process is performed by several attention heads simultaneously. Each head can learn a different type of relationship. 
For example:
Head 1: focuses on grammatical relationships, such as “it” → “cat.”
Head 2: focuses on positional relationships, such as nearby words.
Head 3: focuses on semantic relationships, such as “tired” being related to “cat.”
Head 4: may focus on relationships between verbs and their subjects.
Each attention head produces its own output. 
These outputs are then concatenated and passed through a linear layer to produce the final representation.
In simple terms, multi-head self-attention allows the Transformer to look at the same sentence from multiple perspectives at the same time, helping it understand both the meaning of individual words and their relationships with other words.
