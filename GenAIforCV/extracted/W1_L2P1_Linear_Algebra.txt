MatrixBasic Operations
Matrix Addition: Just element-wise addition. Dimensions of the two matrices must be same. 



Matrix Subtraction: Element-wise subtraction. Dimensions of the two matrices must be same.



Matrix Multiplication: Multiply each row with each column. Column dimension of the first matrix should be same as row dimension of the second matrix. If A is of dimension [3x4] and B is [4x5], Product matrix (A.B) will be [3x5]

Geometric Interpretation of Singular Matrix
A singular matrix collapses space into a lower dimension. For example, a transformation represented by a singular matrix may compress a two-dimensional plane into a single line. Because information is lost during this transformation, the original data cannot be uniquely recovered, which is why the matrix has no inverse.
Importance in Machine Learning
Singular matrices often appear when:
Features are highly correlated (multicollinearity).
Duplicate features exist in a dataset.
The number of features exceeds the number of samples.
Computing matrix inverses in linear regression.
When a matrix is singular, algorithms typically use techniques such as regularization, matrix factorization, or the Moore–Penrose pseudoinverse instead of a standard matrix inverse.
Understanding singular matrices is important because they help explain why some machine learning problems do not have unique solutions and why alternative numerical methods are often required.
