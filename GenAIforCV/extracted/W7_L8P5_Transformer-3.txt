Transformers
Transformer is a powerful architecture for generative modelling that uses attention mechanisms to learn relationships between different elements of a sequence. 

Attention allows the model to assign different levels of importance to input tokens when generating an output, enabling it to focus on the most relevant information. 

A key component is self-attention, in which each token in a sequence interacts with every other token to determine their contextual relationships. 

This enables the Transformer to understand dependencies between words or tokens, even when they are far apart in the sequence.
[IMAGE: image.png.png 4.2x6.0in]
Figure Source: Ashish Vaswani et. al. Attention is All You Need, NIPS 2017

--- slide 4 ---
Transformers further improve this process through multi-head attention, which runs several self-attention mechanisms in parallel, with each head learning to capture different types of relationships or patterns within the data.

 By combining these attention mechanisms with positional information and feed-forward layers, Transformers can effectively model complex dependencies and generate coherent text, images, code, and other forms of data. 

In generative models such as GPT, this architecture is used autoregressively, where the model predicts the next token based on the previously generated tokens, allowing it to produce new sequences that resemble the patterns learned during training.

Transformer for Vision Tasks
Transformers can be used for computer vision by treating an image as a sequence of smaller regions, or patches, rather than processing the entire image at once. 

For example, in the Vision Transformer (ViT), an image is divided into fixed-size patches, such as 16×16 pixels, and each patch is converted into a numerical vector called an embedding. 

These patch embeddings are then given positional information so that the model can understand where each patch is located in the image. 

The embeddings are passed through Transformer encoder layers, which use self-attention to learn relationships between different parts of the image. 

This allows the model to identify both local features and long-range dependencies, such as relationships between objects that are far apart. The resulting representations can then be used for tasks such as image classification, object detection, image segmentation, and image generation. 

Thus, Transformers provide a powerful alternative to traditional convolutional neural networks (CNNs) for many computer vision applications.

A CNN uses convolutional filters to first identify local features such as edges, shapes, and textures. As the information moves through deeper layers, the CNN gradually combines these local features to understand that the person is holding the flag.

--- slide 8 ---
A Transformer, on the other hand, conceptually divides the image into patches and uses self-attention to determine how important each patch is to every other patch. 

It can directly learn that the patch containing the person's hand is related to the patch containing the flag, even if they are relatively far apart.

CNNs are naturally good at learning local patterns and spatial features, while Transformers are particularly powerful at learning relationships between different regions of an image. 

Modern vision systems often combine ideas from both approaches to get the advantages of each.

Input Embedding
Input embedding in a Transformer is the process of converting text tokens into numerical vector representations that the model can process mathematically. 

The input text is first tokenized into smaller units, such as words, subwords, or individual tokens. 

Each token is then mapped to a dense, fixed-dimensional vector using a learnable embedding matrix. 

These embeddings provide a continuous representation of the tokens and allow the model to capture meaningful semantic and syntactic relationships between them. 

During training, the embedding vectors are learned such that tokens with similar meanings or usage patterns tend to have similar representations in the vector space. 

The resulting embeddings are then combined with positional information and supplied to the Transformer layers for further processing.

--- slide 20 ---
Positional encoding is a technique used to provide information about the order and position of tokens within a sequence. 

Since Transformers process all tokens in parallel and self-attention does not inherently encode their sequential order, the model requires additional positional information to distinguish between different token arrangements. 

To address this, a unique positional vector is generated for each position in the sequence and added to the corresponding token embedding before the representation is passed into the Transformer layers. 

This allows the model to incorporate information about the relative and absolute positions of tokens, enabling it to understand the order of words and capture relationships that depend on their positions within the sequence.
[IMAGE: image.png.png 3.8x5.5in]
Transformer Architecture
Positional Encoding
Figure Source: Ashish Vaswani et. al. Attention is All You Need, NIPS 2017

--- slide 21 ---
Positional vectors are typically generated using sine and cosine functions with different frequencies, creating unique patterns for different positions in the sequence and enabling the model to capture relationships between positions. 

These positional encodings are added to the corresponding token embeddings, allowing the Transformer to distinguish between sequences in which the same words appear in different orders. 

For example, the sentences “dog bites man” and “man bites dog” contain the same words but have different meanings because their word order is different. 

By incorporating positional information into the token representations, mechanisms such as self-attention can effectively capture both the contextual relationships and positional dependencies between tokens, enabling the model to better understand the structure and meaning of the sequence.
