Training of The Neural Network
Backpropagation is the fundamental learning algorithm used to train neural networks. It efficiently determines how each weight in the network should be updated to minimize the prediction error.

The process begins when the neural network makes a prediction. This prediction is compared with the actual target value, and the difference between them is measured using a loss (error) functions.

Backpropagation tells us: 
How much did each weight contribute to that error?
Once we know that, we can adjust the weights to improve the network.

--- slide 6 ---
Backpropagation consists of two main phases:
Forward Pass
Input data is passed through the network. 
In each hidden layer, weighted inputs are summed and a non-linear activation function is applied. 
The output of one layer becomes the input to the next layer. 
The network produces a final prediction. 
The loss (error) is computed using a loss function such as Mean Squared Error (MSE) or Cross-Entropy. 

Backward Pass (Backpropagation)
The error is propagated backward from the output layer to the input layer. 
Gradients are calculated using the chain rule. 
Each weight receives a gradient indicating how much a change in that weight would affect the loss.

Backward Pass : Backpropagation
Backpropagation minimizes the cost (loss) function by updating the network's weights and biases using an optimization algorithm such as gradient descent.

The error gradient with help of learning rate indicates how much each parameter should be changed, and in which direction, to reduce the loss.

During backpropagation, these gradients are propagated from the output layer back to the input layer, hence the name backpropagation.

Gradients are computed directly at the output layer and then propagated through the hidden layers using the chain rule of calculus.

BackpropagationSpace Complexity
The space complexity of backpropagation is determined by the memory required to store the model parameters, intermediate activations, and gradients during training.

Storing Model Parameters: The weights and biases of the network are stored throughout training. If W is the total number of trainable parameters, the required memory is O(W). 

Storing Intermediate Activations: The output activations of each layer are cached during the forward pass for use in gradient computation during backpropagation. The memory required grows linearly with the number of layers and neurons. 

Storing Gradients: Backpropagation stores the gradient corresponding to each trainable parameter. Since there is one gradient per weight and bias, the memory required is O(W). 

Overall Space Complexity: The overall space complexity is O(W), with additional memory required for storing intermediate activations during training.

--- slide 20 ---
BackpropagationSpace Complexity (Optimization : Checkpointing)
Standard implementation requires O(N) space to store activations. Checkpointing (or selective re-computation) trades computation time for reduced memory usage.

Standard approach (O(N) space): Store all intermediate activations during the forward pass. Fast computation but high memory usage. 

Re-computation approach (O(1) space, O(N²) time): Recompute activations during the backward pass instead of storing them. Minimizes memory usage but increases computation time. 

Checkpointing: Store only selected activations and recompute the rest as needed. Balances memory and computation, with space complexity between O(1) and O(N).
