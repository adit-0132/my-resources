Sequence Modelling
Sequence modeling is a fundamental task in machine learning that involves learning temporal dependencies from ordered data such as text, speech, and time-series signals.

Sequential models in machine learning are algorithms designed to process and learn from ordered or time-dependent data, where the sequence of observations contains meaningful information which is modelled by capturing dependencies between previous and current elements to make accurate predictions.

Popular Sequential models includes Recurrent Neural Network (RNN), Long Short-Term Memory (LSTM), Gated Recurrent Unit (GRU), Transformer, etc.

--- slide 4 ---
Why sequential modeling is important?
Many real-world data sources are inherently ordered, and the meaning of each element often depends on what came before it.

Unlike traditional machine learning methods that treat each input independently, sequence learning models capture temporal and contextual relationships between consecutive data points, leading to more accurate predictions and better understanding of patterns.

Some key reasons sequence learning is important include:
Captures temporal dependencies: It learns relationships between past and current observations, which is essential for time-series forecasting, speech recognition, and video analysis. 

Preserves context: In natural language processing (NLP), the meaning of a word often depends on the surrounding words. Sequence models use context to improve tasks such as machine translation, sentiment analysis, and text generation. 

Handles variable-length inputs: Sequence learning models such as RNNs and LSTMs can process sequences of different lengths without requiring a fixed-size input.

--- slide 5 ---
Models long-term relationships: Advanced sequence models like LSTMs can retain important information over long intervals, enabling them to recognize long-range dependencies that standard neural networks struggle to capture. 

Improves prediction accuracy: By leveraging historical information instead of treating observations independently, sequence models generally achieve better performance on sequential data. 

In summary, sequence learning is essential because it enables machine learning models to understand the order, context, and temporal dynamics of data. 

This capability is critical for applications such as language modeling, video summarization, handwriting recognition, machine translation, stock price prediction, weather forecasting, and healthcare monitoring, where the sequence of events carries important information.

Different Recurrent Neural Networks
The main types of Recurrent Neural Network (RNN) models are classified based on the relationship between input and output sequences. These architectures are designed to handle different sequence modeling tasks.
One-to-One

Not a typical sequential model. 
One input → One output. 
Example: Vanilla Neural Network.
One-to-Many

One input → Multiple outputs (a sequence). 
The RNN generates an output sequence from a single input. 
Example: Image captioning (input: image, output: sentence).
Many-to-One

Multiple inputs (a sequence) → One output. 
The RNN processes an input sequence and produces a single prediction. 
Example: Sentiment analysis, video activity recognition.
Many-to-Many

Multiple inputs (a sequence) → Multiple outputs (a sequence). 
The RNN maps an input sequence to an output sequence. 
Example: Neural machine translation, video summarization.
